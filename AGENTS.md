# TANAW repository instructions

- Read `CLAUDE.md` for shared product, data, and repository conventions.
- For frontend work, read `docs/project-vision.md` and `client/AGENTS.md`.
- Treat metrics, funding joins, rankings, boundaries, and station readings as unavailable until supported by repository data and a source. Never fill missing values with zero.
- Describe evidence neutrally. Do not claim that funding caused an environmental outcome or that a pattern establishes wrongdoing.
- Do not use em dashes in user-facing copy or project documentation.
- The `.claude/` directory contains Claude Code configuration. For Codex-specific project instructions, keep guidance in `AGENTS.md` files and use the skills available in the current Codex environment. Do not assume Claude hooks or settings run in Codex.
